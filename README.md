Removedor de Pontos
Utilitário simples para Windows que remove pontos, traços, barras, espaços, letras e outros caracteres de um texto, mantendo apenas os números.

O resultado é automaticamente colocado na área de transferência do Windows.

Exemplos
CPF
Entrada:
123.456.789-00

Saída:
12345678900

CNPJ
Entrada:
12.345.678/0001-90

Saída:
12345678000190

NF
Entrada:
NF-e: 123.456.789

Saída:
123456789
